Политика конфиденциальности qPokoy

Редакция от 3 октября 2026 г.

1. Оператор и контакт

Оператор персональных данных — Синюк Владимир Андреевич, самозанятый (налог на профессиональный доход). Вопросы об обработке персональных данных и запросы субъектов принимаются по адресу support@qpokoy.ru. Почтовый адрес для обращений: 607150, Нижегородская обл., Мухтолово, пл. Советская, д. 14.

2. Какие сведения обрабатываются

В сервисе обрабатываются электронная почта, идентификатор аккаунта, технические данные авторизации и сессии, IP-адрес при обращении к сервису и производный от него технический хэш для ограничения частоты запросов и защиты от злоупотреблений, введённые пользователем доходы, категории, настройки и технические события, необходимые для работы и безопасности сервиса. При использовании внешних способов входа могут также обрабатываться сведения, передаваемые выбранным провайдером авторизации. Пароли от аккаунтов внешних провайдеров qPokoy не получает.

При оплате также могут обрабатываться идентификатор платежа, выбранный тариф, сумма, валюта, статус и время платежа, сведения о возврате, а при подключении автопродления — технический идентификатор сохранённого способа оплаты, предоставленный платёжным сервисом. Полный номер банковской карты и CVC/CVV qPokoy не запрашивает и не хранит.

3. Цели и основания обработки

Регистрация и вход в аккаунт, предоставление функций учёта доходов, синхронизация, техническое обслуживание, обеспечение безопасности, поддержка пользователей, проведение и учёт платежей и возвратов, управление сроком платного доступа и автопродлением, а также исполнение предусмотренных законом обязанностей.

Для регистрации аккаунта, предоставления пробного и оплаченного доступа и исполнения пользовательских отношений обработка необходимых персональных данных осуществляется на основании пункта 5 части 1 статьи 6 Федерального закона № 152-ФЗ — для заключения и исполнения договора по инициативе пользователя. Для исполнения обязанностей, прямо установленных законом, применяются соответствующие предусмотренные законом основания. Если для отдельной операции потребуется согласие на обработку персональных данных, такое согласие запрашивается отдельно от оферты и иных документов.

4. Инфраструктура и получатели

Для работы сервиса используется облачная инфраструктура Yandex Cloud, включая API Gateway, Cloud Functions, YDB и Yandex Cloud Postbox для отправки служебных писем (подтверждение электронной почты, восстановление пароля и иные технические уведомления). Ресурсы проекта, обрабатывающие данные приложения, настроены в регионе ru-central1. Для входа через внешний сервис используется Яндекс; qPokoy получает только сведения, которые Яндекс передаёт в рамках авторизации, и не получает пароль от аккаунта Яндекса. Данные пользователей не продаются.

После подключения оплаты для приёма платежей будет использоваться платёжный сервис ЮKassa. При оформлении оплаты пользователь может быть перенаправлен на платёжную страницу ЮKassa, где платёжные реквизиты обрабатываются платёжным сервисом. qPokoy получает только сведения, необходимые для подтверждения платежа, предоставления доступа, возврата и, при отдельном согласии пользователя, последующих автоплатежей. Для автопродления qPokoy может хранить идентификатор сохранённого способа оплаты, выданный ЮKassa, но не полный номер карты и не CVC/CVV.

5. Порядок обработки, сроки хранения и защита

Обработка персональных данных в qPokoy осуществляется преимущественно автоматизированно с использованием информационных систем сервиса. Данные используются только для целей, указанных в настоящей политике, и передаются указанным в разделе 4 получателям только тогда, когда это необходимо для работы соответствующей функции.

Данные аккаунта, пользовательские записи, категории и настройки хранятся, пока существует аккаунт и они необходимы для предоставления сервиса, если более длительное хранение не требуется законом. Отсутствие платной подписки само по себе не означает автоматического удаления пользовательских записей. Сведения о платежах и возвратах хранятся в объёме и в течение срока, необходимого для исполнения договора, обработки возвратов, разрешения обращений и выполнения обязательных требований законодательства. Технические сведения авторизации и безопасности хранятся в объёме и в течение периода, необходимого для защиты сервиса и разбора технических инцидентов.

Для защиты персональных данных применяются правовые, организационные и технические меры. В qPokoy используются разграничение доступа по аккаунтам, серверная проверка прав на пользовательские данные, управление сессиями и ограничение доступа к инфраструктуре сервиса. Передача данных между браузером пользователя и сервисом осуществляется по защищённому сетевому соединению.

6. Доступ, исправление и удаление

Пользователь вправе обратиться за сведениями о своих персональных данных, их уточнением, блокированием либо удалением в предусмотренных законом случаях по адресу support@qpokoy.ru. Для защиты аккаунта может потребоваться подтверждение принадлежности запроса пользователю. В приложении доступно самостоятельное удаление всех доходов без удаления аккаунта, а также полное удаление аккаунта. При полном удалении аккаунта из рабочей базы удаляются связанные с ним доходы, категории, настройки, активные сессии и данные авторизации.

При удалении аккаунта данные пользователя удаляются из рабочей базы, кроме сведений, которые оператор обязан или вправе сохранять по закону. После прекращения обработки отдельные сведения могут сохраняться в объёме и на сроки, прямо требуемые законом, включая обязательные учётные документы после запуска оплаты. Если для пользовательских данных будет настроено резервное хранение, порядок и сроки удаления из резервных копий будут закреплены отдельно.

7. Изменение политики

При изменении функций сервиса или перечня обработчиков публикуется новая редакция политики с актуальной датой. По вопросам обработки персональных данных: support@qpokoy.ru.
